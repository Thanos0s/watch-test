# ⚡ Quick Start: Connect Your Smartwatch

## 5 Simple Steps

### 1️⃣ Prepare Watch
```
Turn ON Bluetooth on your watch
↓
Put it in pairing mode (check manual)
↓
Wear it on your wrist
```

### 2️⃣ Navigate to Vitals Screen
```
Open PrakritiDesk in Chrome/Edge
↓
Complete check-in (ABHA ID + OTP)
↓
Accept privacy consent
↓
Reach "Vitals & Pulse Check" screen
```

### 3️⃣ Click Pair Button
```
┌────────────────────────────────────┐
│   🔗 Tap to Pair Pulse Sensor     │
│      / Smartwatch                  │
└────────────────────────────────────┘
```

### 4️⃣ Select Your Device
```
Browser popup appears:
┌────────────────────────┐
│  Select a device:      │
│  ○ Fitbit Charge 5     │  ← Click your device
│  ○ Polar H10 123456    │
│  ○ Mi Band 6           │
│  [Cancel]   [Pair]     │
└────────────────────────┘
```

### 5️⃣ View & Sync
```
┌─────────────┐  ┌─────────────┐
│ Heart Rate  │  │   SpO2      │
│     75 ❤️   │  │    98 🫁    │
│    bpm      │  │     %       │
└─────────────┘  └─────────────┘
        ↓
Stay still 10-15 seconds
        ↓
✓ Vitals recorded — HR 75 bpm, SpO2 98%
        ↓
Click "Continue to Symptoms ➜"
```

---

## 🚨 Common Issues (Quick Fix)

| Problem | Solution |
|---------|----------|
| **No devices show up** | Make sure watch is in pairing mode |
| **"Not supported" error** | Use Chrome or Edge browser |
| **Can't pair** | Disconnect watch from phone first |
| **Taking too long** | Stay completely still |
| **No SpO2 reading** | Normal! Most watches only do HR |
